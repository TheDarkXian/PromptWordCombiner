# 函数体引用语法约定

## 目标

函数节点把提示词视为函数体。为了让入口参数和全局变量在视觉和语义上分开，函数体内采用两种引用语法：

| 语法 | 含义 | 示例 |
| --- | --- | --- |
| `[[参数名]]` | 函数入口参数 | `请根据 [[主题]] 生成大纲` |
| `--变量名--` | 全局变量、项目变量或上游返回值 | `沿用 --世界观-- 的设定` |

## 入口参数

`[[参数名]]` 会被自动解析成函数节点的入口参数。用户不需要手动新增参数，写入函数体后系统会同步生成参数列表。

```text
请根据 [[角色名称]] 和 [[角色背景]] 生成角色描述。
```

上面的函数体会生成两个入口参数：

- `角色名称`
- `角色背景`

参数名 V1 只允许直接名称，不支持字段访问：

```text
[[角色名称]]        ✅
[[角色表[0].名称]]  ❌
[[角色表.名称]]     ❌
```

## 全局变量

`--变量名--` 用于显式读取函数外部上下文，例如项目变量、全局变量或已经保存的上游返回值。

```text
请保持 --世界观-- 的风格，扩写 [[角色名称]]。
```

这个例子中：

- `[[角色名称]]` 是函数入口参数
- `--世界观--` 是全局变量引用

## 兼容策略

旧存档中已有的 `{{变量名}}` 暂时保留为兼容语法，用于读取旧的全局变量引用。但新 UI、新文档和新功能不再推荐使用 `{{...}}`。

严格函数节点中如果继续出现 `{{...}}`，诊断面板会提示用户迁移：

- 入口参数改为 `[[参数名]]`
- 全局变量改为 `--变量名--`

## 设计原则

1. 入口参数来自函数体源码，而不是手动维护的参数表。
2. 全局变量必须显式标记，避免函数体无意读取外部状态。
3. 引用语法应便于视觉高亮：入口参数和全局变量使用不同颜色。
4. 表字段、循环、嵌套表访问暂不进入 V1，后续再设计专门语法。
